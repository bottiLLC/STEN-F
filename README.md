# STEN-F (Simple Tough Effective Next-generation Finance)

[![CI](https://github.com/bottiLLC/STEN-F/actions/workflows/ci.yml/badge.svg)](https://github.com/bottiLLC/STEN-F/actions/workflows/ci.yml)

**STEN-F** は、既存のクラウド会計ソフト（SaaS）によるデータの囲い込みや高額なサブスクリプションから開発者・中小企業・個人事業主を解放するために生まれた、**100% Pure Python 製のオープンソース経理・会計アプリケーション**です。

日本の複式簿記の標準的な帳票様式（振替伝票・仕訳帳・総勘定元帳・合計残高試算表・左右対照 B/S・段階利益 P/L）に完全準拠し、**「PDF/画像の領収書・請求書をアップロードするだけで、AI が自動仕訳を行い振替伝票へ展開する」** というシームレスな実務ワークフローを最前面に備えています。

軽量かつ堅牢な **Streamlit** を GUI フレームワークに採用し、**Clean Architecture（クリーンアーキテクチャ）** に基づいて設計されています。すべてのデータはローカルの SQLite（非同期 SQLAlchemy 2.0）に保存され、財務データの完全な主権を手元に保持できます。

## 🏴 開発・運用哲学 (Philosophy)

1. **This is your Stengun (これはステンガンだ):** シンプルで、タフで、実戦で勝つための武器（[ステン短機関銃](https://ja.wikipedia.org/wiki/%E3%82%B9%E3%83%86%E3%83%B3%E7%9F%AD%E6%A9%9F%E9%96%A2%E9%8A%83)）のように、過剰な装飾を削ぎ落とした強靭で壊れにくいシステムを目指します。
2. **Of course it's free (当然無料だ):** 基礎的な経理・会計ソフトウェアは、自らの手でホストでき、完全に無償であるべきです。
3. **No Vendor Lock-in (ベンダーロックインの排除):** あなたの財務データは人質ではありません。生の SQL や Python スクリプトからいつでも瞬時にアクセス・抽出可能であるべきです。
4. **Local First (ローカルファースト):** 外部のネットワーク障害や SaaS のサービス終了に怯える必要はありません。データもアプリケーションも手元のマシンで動き続けます。
5. **Don't pay for apps, pay for AI (アプリではなくAIに払う):** 毎月の固定利用料を支払うのではなく、業務を真に自動化・高速化する「AI推論（レシートOCRによる仕訳候補抽出）」の従量制 API 利用料に直接支払うべきです。

## ⚡ 主な機能一覧 (Features)

### 1. 📄 日常の記帳 (AI OCR起点 ＆ 複式簿記の標準表示)
* **AI OCR 証憑自動読取起点ワークフロー:** PDF や画像（PNG/JPG）の領収書・請求書をドラッグ＆ドロップするだけで、AI が取引日・金額・取引先・インボイス登録番号・勘定科目を瞬時に自動抽出。
* **一般的な振替伝票 UI:** 左右対照（左: 借方 / 右: 貸方）の複式簿記形式で AI 抽出結果を自動展開・確認・微修正。複数行の複合仕訳にも対応。
* **リアルタイム貸借一致検証（ポカヨケ）:** 借方合計と貸方合計のバランスをリアルタイムに計算し、不一致時の差額警告および誤登録防止を徹底。
* **仕訳帳 (General Journal):** すべての取引を日付順に一覧表示。取引先・摘要・勘定科目・証憑有無・期間での高速検索・フィルタリング、ワンクリック CSV 出力、論理削除に対応。
* **総勘定元帳 (General Ledger):** 勘定科目ごとに前期繰越から取引ごとの借方・貸方・差引残高推移を 3 欄式で時系列に把握。

### 2. 📊 帳簿・決算 (試算表 ＆ 財務諸表)
* **合計残高試算表 (Trial Balance / T-B):** すべての科目の借方合計/残高および貸方合計/残高を標準 7 列で対照集計し、貸借一致バランスを瞬時に検証。
* **貸借対照表 (Balance Sheet / B-S):** 資産の部 ＝ 負債の部 ＋ 純資産の部 の左右対照レイアウトで期末の財政状態を表示。
* **損益計算書 (Profit & Loss / P-L):** 日本の会計基準・税務申告基準に準拠した段階利益（売上総利益・営業利益・経常利益・税引前当期純利益・当期純利益）の階層表示。
* **決算書 PDF のワンクリック出力:** バックグラウンド処理により UI をブロックせず、美しい帳票 PDF を生成・ダウンロード。

### 3. ⚖️ 期首設定 ＆ 電帳法・インボイス対応
* **期首残高設定 (B/S):** 事業年度開始時の資産・負債・純資産（元入金等）の残高を、左右対照・貸借一致チェック付きで設定。
* **適格請求書（インボイス制度）T番号管理:** 取引先ごとに T+13 桁の事業者登録番号をマスタ管理し、仕訳登録時に自動連携・バリデーション。
* **電子帳簿保存法対応の監査証跡:** 削除仕訳の論理削除マーク（`is_deleted`）保持による訂正・削除履歴管理、証憑ファイル（PDF・画像）のローカル安全保管。

### 4. ⚙️ システム管理 ＆ バックアップ
* **年度締め・次期繰越 (Fiscal Year Closing):** 期末の利益剰余金振替および次期開始残高の自動繰越、締め済み年度の編集ロック保護。
* **マスタデータ管理:** 自社情報、会計年度、勘定科目、取引先、よく使う摘要の一括管理。
* **ワンクリック・バックアップ:** SQLite データベース（`-wal`, `-shm` 含む）および設定ファイル（`.env`）をタイムスタンプ付きフォルダへ安全に自動退避。

## 🚀 セットアップと起動方法 (Getting Started)

### 1. 必要環境
* **Python 3.14 以上**
* **uv (Astral)** がインストールされていること（推奨）

### 2. インストール
リポジトリをクローンし、依存関係をインストールします。

```bash
git clone https://github.com/bottiLLC/STEN-F.git
cd STEN-F
uv sync
```

### 3. 環境設定 (.env)
プロジェクトルート直下に `.env` ファイルを作成します（`.env.sample` を複製して作成できます）。

```ini
# データベース接続文字列（SQLite）
DATABASE_URL=sqlite+aiosqlite:///bookkeeping.db

# OpenAI API Key（AI OCR 機能を利用する場合に設定）
OPENAI_API_KEY=sk-proj-...

# OpenAI モデル設定（用途や予算に応じて変更可能）
OPENAI_DEFAULT_MODEL=gpt-5.6-terra
OPENAI_REASONING_EFFORT=high
```

### 4. アプリケーションの起動

#### Windows の場合
プロジェクトルートの `run.bat` をダブルクリックするだけで起動できます。
（初回は自動的に仮想環境の構築と依存パッケージの同期が行われ、ブラウザでアプリが開きます）

#### macOS / Linux の場合
```bash
chmod +x start.command
./start.command
```

#### コマンドラインから直接起動する場合
```bash
uv run streamlit run app.py
```

起動後、ブラウザで `http://localhost:8501` にアクセスしてください。

## 📖 経理業務の基本的な使い方 (Workflow)

```mermaid
graph LR
    A[1. 初期設定] --> B[2. 日常の仕訳入力<br/>(AI OCR & 振替伝票)]
    B --> C[3. 帳簿・試算表の確認<br/>(仕訳帳・元帳・T/B)]
    C --> D[4. 決算書PDF出力<br/>(B/S & P/L)]
    D --> E[5. 年度締め・次期繰越]
```

### ステップ 1: 初期設定（マスタ管理 & 期首残高）
1. 画面左メニューの **「設定・管理」→「マスタ・システム管理」** を開きます。
2. **「自社情報」**: 法人名（または屋号）、住所、代表者役職・氏名を設定します。
3. **「会計年度・年度締め」**: 現在の事業年度（例: 第1期 2026-04-01 〜 2027-03-31）を登録します。
4. **「期首残高設定 (B/S)」画面**: 前期末からの繰越残高（現金、普通預金、資本金など）を左右対照に入力し、貸借が一致した状態で「期首残高を登録する」をクリックします。

### ステップ 2: 日常の仕訳入力 (AIレシート読取 ＆ 振替伝票)
1. **「日常の記帳」→「仕訳入力 (AI/振替伝票)」** 画面を開きます。
2. **AI OCR を利用する場合 (基本フロー)**:
   * 画面上部の「Step 1: 証憑（PDF/画像）のアップロード」エリアに PDF またはレシート画像をドラッグ＆ドロップします。
   * 「🤖 AIで自動読み取りを実行」ボタンを押すと、AI が取引日・金額・取引先・インボイス番号・勘定科目を自動抽出し、下の振替伝票へ自動展開されます。
   * 左右対照の「Step 2: 振替伝票」で内容を確認・微修正し、「💾 この内容で仕訳帳に登録する」をクリックすると、証憑が自動保存され仕訳帳に記録されます。
3. **手動で直接仕訳入力する場合**:
   * 取引日、摘要（よく使う摘要リストまたは直接入力）、取引先、インボイス登録番号（T番号）を入力します。
   * 借方科目・金額、貸方科目・金額を入力します（「➕ 明細行を追加」で複合仕訳にも対応）。
   * 貸借一致インジケーター（✅ 一致）を確認して「💾 この内容で仕訳帳に登録する」をクリックします。

### ステップ 3: 帳簿・試算表の確認
* **「仕訳帳」画面**: 登録したすべての仕訳を日付順に一覧・検索・削除（論理削除）できます。「CSVエクスポート」で全件出力可能です。
* **「総勘定元帳」画面**: 勘定科目ごとにドリルダウンし、前期繰越から取引ごとの借方・貸方・残高推移を 3 欄式で時系列に確認できます。
* **「合計残高試算表 (T/B)」画面**: 月次・年度ごとの借方合計/残高と貸方合計/残高の対照表を確認し、貸借一致バランスを検証します。

### ステップ 4: 決算書 (B/S・P/L) の確認 & PDF 出力
* **「決算書 (B/S・P/L)」** 画面で左右対照の「貸借対照表 (B/S)」および段階利益が表示される「損益計算書 (P/L)」を確認できます。
* 「📑 決算書 PDF を生成・保存」ボタンをクリックすると、帳票 PDF が生成されワンクリックでダウンロードできます。

### ステップ 5: 年度締め (Fiscal Year Closing)
1. **「設定・管理」→「マスタ・システム管理」→「会計年度・年度締め」** タブを開きます。
2. 該当年度の「この年度を締め切る (CLOSED)」ボタンをクリックします。
3. 次期の事業年度名を入力して実行すると、当期純利益が繰越利益剰余金へ自動振替され、次期の期首残高が自動生成されます（締められた旧年度はロックされ、誤修正が防止されます）。

## 🧰 データのバックアップ・過去バージョンからの引き継ぎ手順 (Backup & Migration)

STEN-F はローカルファーストで動作し、すべてのデータはプロジェクト内の特定ディレクトリに独立して保存されます。PC の故障対策としての**定期バックアップ**や、**新バージョンへのデータ引き継ぎ**は以下の手順で行えます。

### 1. 管理・引き継ぎ対象のデータ（3点）

| 対象 | 格納場所（デフォルト） | 内容 |
| :--- | :--- | :--- |
| **① データベース** | `data/sten_f.db`<br>*(※ `-wal`, `-shm` が存在する場合はそれらも含む)* | すべての仕訳データ、勘定科目、取引先、自社情報、会計年度 |
| **② 証憑ストレージ** | `storage/` フォルダ | 仕訳に紐付けられた領収書・請求書の PDF および画像ファイル |
| **③ 設定ファイル** | `.env` | OpenAI API キーなどの環境設定 |

---

### 2. 過去バージョンからのデータ引き継ぎ方法 (Migration)

新しいバージョンの STEN-F へアップデートした場合や、別のフォルダに新バージョンを展開した場合のデータ移行手順です。

#### 📥 手順（ファイルをコピーするだけ）:
1. **アプリの停止**:
   * 旧バージョン・新バージョンの両方の Streamlit サーバー（ターミナル・ブラウザ）を**完全に終了**させます。
2. **旧バージョンからデータをコピー**:
   * 旧バージョンのフォルダから、以下のファイル・フォルダをコピーします：
     * `data/sten_f.db`（※ 初期バージョンの場合は `bookkeeping.db`）
     * `storage/` フォルダの中身すべて
     * `.env` ファイル
3. **新バージョンへ配置**:
   * 新しい STEN-F のフォルダ内の対応する場所に上書き配置します：
     * `data/` フォルダ内に `sten_f.db` を配置（※ 旧ファイル名が `bookkeeping.db` だった場合は `sten_f.db` にリネームして `data/` に配置）
     * `storage/` フォルダ内に過去の証憑ファイル群を配置
     * プロジェクト直下に `.env` を配置
4. **アプリを起動して確認**:
   * 新しい環境で `run.bat`（または `uv run streamlit run app.py`）を実行して起動します。
   * 「仕訳帳」画面や「マスタ管理」画面を開き、過去の仕訳やマスタが正常に表示されることを確認します。

---

### 3. バックアップ方法

#### 方法 A: 画面からのワンクリックバックアップ（DB & 設定ファイル）
1. STEN-F の画面から **「設定・管理」→「マスタ・システム管理」→「バックアップ」** タブを開きます。
2. 「バックアップ先フォルダパス」を確認（または任意の退避先フォルダを指定）します。
3. **「💾 ワンクリック・バックアップを実行」** ボタンをクリックします。
4. 指定したフォルダ内に `YYYYMMDD_HHMMSS/` 形式のタイムスタンプ付きフォルダが作成され、データベースファイル（`-wal`, `-shm` を含む）および `.env` が自動的にコピー・退避されます。

> [!IMPORTANT]
> **証憑 PDF / 画像ファイル（`storage/` フォルダ）のバックアップについて**
> 電子帳簿保存法に対応して蓄積された領収書・請求書ファイルは `storage/` フォルダに保存されます。ファイルサイズが大きくなるため、画面からの DB バックアップと併せて、**`storage/` フォルダごと外付け HDD、NAS、またはクラウドストレージ（Google Drive / OneDrive / Dropbox 等）へ定期的にコピー・同期保存**してください。

#### 方法 B: 手動での完全バックアップ（推奨）
アプリケーションを停止した状態で、以下のファイル・フォルダを別の安全なストレージへ丸ごとコピーします。

```text
STEN-F/
├── data/
│   └── sten_f.db    # ★必須: データベース
├── storage/         # ★必須: すべての証憑 PDF・画像ファイルが格納されているフォルダ
└── .env             # ★必須: APIキー・環境設定ファイル
```

---

### 4. リストア（復旧・別 PC へのデータ移行）手順

マシントラブルからの復旧時や、新しい PC へ環境を移行する際の手順です。

1. **移行先 PC での準備**:
   * Python 3.14+ および `uv` をインストールします。
   * リポジトリをクローンまたはソースコードを展開し、`uv sync` で環境をセットアップします。
2. **アプリケーションの完全停止**:
   * STEN-F が起動している場合は、ターミナルおよびブラウザを**完全に終了**させてください。
3. **バックアップデータの配置（上書きコピー）**:
   * 退避させておいた **`data/sten_f.db`**、**`.env`**、および **`storage/` フォルダ** を、移行先プロジェクトの所定のディレクトリに上書き配置します。
4. **起動と動作確認**:
   * `run.bat`（または `uv run streamlit run app.py`）で起動します。
   * 「仕訳帳」画面で過去の仕訳が表示されること、および「証憑」欄から PDF / 画像ファイルが正常にダウンロードできることを確認します。

## 🏗 アーキテクチャ構成 (Clean Architecture)

```text
app/
├── app.py                      # Streamlit メインエントリポイント (st.navigation / nest_asyncio)
├── config.py                   # Pydantic Settings 設定管理 (.env)
├── container.py                # 依存関係注入 (Dependency Injection)
├── core/                       # 共通ユーティリティ (Logging, Resilience)
├── domain/                     # ドメイン層 (Pydantic V2 モデル、インターフェース)
│   ├── constants/              # 会計定数・税率定義
│   ├── interfaces/             # リポジトリ抽象インターフェース
│   ├── models/                 # 仕訳・勘定科目・年度・領収書ドメインモデル
│   └── prompts/                # OpenAI OCR 推論プロンプト
├── infrastructure/             # インフラ層 (外部サービス、DB、リポジトリ具象実装)
│   ├── db/                     # SQLAlchemy ORM モデル、セッション管理
│   ├── external/               # OpenAI OCR, PDF 生成, バックアップ, ファイル保存
│   └── repositories/           # データアクセス具象実装
├── application/                # アプリケーションサービス層 (ユースケース)
│   └── services/               # 仕訳・元帳・マスタ・決算サービス
└── ui/                         # プレゼンテーション層 (Streamlit UI)
    ├── app_pages/              # 各画面 (1_journal_entry, 2_journal_history, 3_general_ledger, 4_trial_balance, 5_financial_statements, 6_opening_balance, 7_master_management)
    ├── async_helper.py         # Streamlit 非同期実行ヘルパー (nest_asyncio)
    ├── di.py                   # UI からのサービス解決
    └── styles.py               # 会計ソフト・簿記専用の共通CSSスタイル
```
